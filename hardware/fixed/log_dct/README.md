# Integer log and DCT

`mfcc_fixed_log_dct.sv` accepts 26 unsigned60 Mel transactions per frame and emits 13 signed40/F24 coefficients. Both boundaries support ready/valid stalls. Data, frame number, Mel/coefficient index, last, signed8 BFP s, and error metadata travel together. Legal s is [-2,24], and Mel common-unit energy is T·2^(-43-2s). Invalid exponents propagate an error; malformed Mel indices/last/frame metadata mark all output coefficients of the collected frame. A subsequent well-formed frame clears that error. Synchronous active-low reset discards unfinished work and valid state without resetting memory contents.

The floor is the common binary64 value 1e-12, exactly 4951760157141521 / 4951760157141521099596496896. Each legal s has an offline-generated integer ceil threshold: floor when T is less than that threshold. All 27 thresholds are identical to those obtained from exact decimal 1/10^12. Equality with either non-dyadic floor is unreachable on these integer energy grids.

Above floor, normalize T by truncation to unsigned32/F31 in [1,2). Perform 30 binary-log fractional iterations: square with unsigned64 precision, shift by 31, then when the result is at least 2, shift once more and append a one bit. Each exact 32-bit square uses three registered 16-bit products, `hi²`, `hi*lo`, and `lo²`, followed by the registered unsigned64 sum `(hi²<<32)+(hi*lo<<17)+lo²`. The next cycle updates the normalized mantissa and fraction. No extra truncation or rounding is introduced. The logarithm base-2 integer part includes the Mel exponent. Multiply the signed40/F30 logarithm by positive LN2_Q30=744261118, retaining a signed71 product. RNE by 36 bits gives signed30/F24 natural log. The floor output is -463571610. On valid inputs, logs lie between ln(1e-12) and ln(2^21), so signed30/F24 is sufficient.

The DCT uses fixed signed31/F30 coefficients generated from the frozen orthonormal 13×26 matrix. Coefficients and signed61 products are registered separately; products accumulate in increasing Mel index into signed64, and a separate final cycle applies one RNE shift of 30. The frozen coefficient absolute row sums and log bounds give an accumulator magnitude bound of 2538068713882680420 (<2^62). Signed40/F24 output accommodates silence C0 near -140.89, which would overflow signed32/F24. The log conversion's signed71 LN2 product also has a separate register before rounding. These registers change transaction latency without changing any integer arithmetic operation or rounding position.

The log block admits one transaction at a time. The DCT holds 26 logs in one inferred 32×30 block RAM, using a synchronous read followed by one MAC per Mel value. Arrays have no full reset or next copy. All newly authored RTL follows the two-process and synchronous reset rules; coefficient case modules are purely combinational and contain no forbidden loops/functions/initial blocks. `scripts/verify_fixed_integer_rtl.py` exercises all model corpus transactions, floor boundaries at every legal s, invalid exponents, reset, gaps, stalls, malformed frame metadata and recovery. Actual results belong to immutable build run directories, not this source description.

Portable C does not require a native 128-bit type for the log conversion. Let a be signed log2/F30, h=floor(a/64), l=a-64h, p=l·744261118, and b=h·744261118+floor(p/64). All intermediates fit signed64. Set q=floor(b/2^30), r=b mod 2^30. Round q upward if r>2^29, or if r=2^29 and either p mod64 is nonzero or q is odd. This reproduces signed71 multiplication followed by RNE>>36 exactly, including negative ties. The independent Python test checks that decomposition against arbitrary-precision multiplication.
